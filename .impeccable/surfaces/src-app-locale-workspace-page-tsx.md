# Decision work surface brief

Workspace is the place to create one next move; Decision Desk is the durable
home for active moves, waiting signals, and returned reality. Route names remain
stable, while user-facing language follows the decision loop rather than the
legacy project/workspace model.

The idle workspace shows a continuous three-beat sequence before the input and
keeps one primary action. The empty Decision Desk demonstrates what will
accumulate instead of presenting a blank archive. On the first return, collect
the observation before revealing the old wording so the UI cannot contaminate
the user's recall.

Preserve local-first behavior, due-return priority, explicit adoption, honest
example labels, keyboard access, and the existing paper/harbor visual world.
