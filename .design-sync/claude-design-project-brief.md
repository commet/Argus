# Claude Design 브리핑 — 프로젝트 페이지 "결정 계약(Decision Contract)" 카드

> 이 프로젝트의 컴포넌트(`window.ArgusDS.*`)와 토큰을 그대로 쓰도록 이미 설정돼 있습니다.

---

프로젝트 페이지의 **"결정 계약" 카드**를 더 멋지게 다시 디자인해줘. 이 카드는 하나의 결정이
거치는 **생애주기 4상태**를 보여주는데, 지금은 평범한 카드라서 "봉인 → 기다림 → 정산"이라는
의식(ritual)의 무게가 안 느껴져. 항해 일지(logbook)에 봉인된 한 페이지처럼, **깊이감 있게
(은은한 3D/입체)** 만들고 싶어.

## 반드시 이 디자인 시스템의 부품·토큰으로

- 컴포넌트: `Card`, `Badge`(variant `gold`/`ai`/`risk-critical`/`risk-manageable`), `Button`(`accent`/`ghost`).
- 토큰만(하드코딩 금지): `--surface`/`--bg`/`--ai`/`--collab`, 텍스트 `--text-primary/secondary/tertiary`,
  골드 `--accent`/`--gradient-gold`, 성공 `--success`, 위험 `--risk-critical/-manageable`,
  그림자 `--shadow-sm/md/lg`(깊이는 그림자로), 세리프 `--font-display`, 숫자·날짜는 `--font-mono`.
- 톤: 양피지+잉크 "captain's logbook". 골드는 핵심 순간에만. 화려함이 아니라 **신뢰/무게감**.

## 4가지 상태 (각각을 카드 변형으로 디자인 — 한 화면에 4장 나란히 보여줘 비교되게)

1. **봉인 전 (SEAL)** — 골드 강조. "이 결정을 예측으로 봉인하기". Sparkles 아이콘,
   예측 N개 미리보기 + 확인일 선택 칩(1주/2주/1달) + `Button variant="accent">약속하고 봉인</Button>`.
   느낌: 펼쳐진 빈 계약서, 봉인을 기다리는.
2. **대기 (WAITING)** — 중립·차분. Clock 아이콘, "○월 ○일에 확인 예정 · 예측 N개".
   느낌: 밀랍으로 봉인돼 서랍에 든 편지. 조용함.
3. **확인일 도래 (DUE)** — 골드 테두리로 깨어남. "물어볼 게 N개 있어요". 예측마다
   질문 한 줄 + 판정 버튼(가설=적중/빗나감, 위험=발생/회피, 사람판단=맞았음/아니었음, 부분, 아직모름).
   느낌: 봉인이 다시 열리는 순간.
4. **검증됨 (VERIFIED)** — 그린(`--success`). Check 아이콘, "검증된 항해" + 요약
   ("위험 2개 회피 · 가설 1개 적중"), 예측별 판정 라벨. 느낌: 도장이 찍혀 완결된 기록.

## 예측의 3가지 출처 (아이콘 + 색으로 구분)

- **가설(governing_idea)** — Target 아이콘, 골드 계열 — "내가 건 핵심 베팅".
- **위험(risk)** — AlertTriangle, `--risk-*` 계열 — "일어날까 두려웠던 것".
- **사람 판단(actor)** — GitBranch, 잉크/뉴트럴 — "사람이 정해야 했던 갈림".

## "멋지게 / 입체" 방향 (취향껏 제안해줘, 과하지 않게)

- **깊이**: 다단 그림자 + 살짝 들린 카드, 호버 시 부드럽게 떠오름(`--shadow-lg`).
- **봉인 메타포**: 상태가 진행될수록 시각적으로 "봉인 → 잠금 → 개봉 → 도장"이 느껴지게
  (밀랍 도장/엠보싱/접힌 모서리 같은 디테일을 토큰 색으로 — 골드 도장 등).
- **상태 진행 표시**: 4상태를 잇는 가는 진행 라인/스텝(현재 상태 골드)도 좋음.
- 풀 3D(회전·캔버스)는 신중히 — 신뢰감을 해치면 안 됨. "종이/잉크의 물성"에서 오는 입체가
  이 브랜드엔 더 맞음. 진짜 3D를 시도하려면 한 장면만(예: 봉인 도장 찍히는 순간) 제안해줘.

## 동작

- 호버/포커스 인터랙션은 부드럽게(스프링), `prefers-reduced-motion`이면 정적.
- 데스크톱 4열 비교, 모바일 1열 세로 스택.
