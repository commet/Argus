## 실측 발견 (생성 eval, 아침 리뷰 필수)

- **과발동이 실전에서 심각(R2 run):** MCP 52/90 · 플러그인 47/90. 손코퍼스(0/8)와 정반대 — 결정 밀도 높은 대화에선 무관 작업요청·일정·잡담에 argus_predict/capture가 마구 발사됨. **출시 전 최우선 스파인 문제.** R2에서 절제 지시 강화, 다음 run이 효과 측정.
- **MCP 정산 recall 낮음:** 13/38 — 정산 턴('업데이트: churn 8%로 올랐어')에 resolve 대신 check_in 발사. 열린 예측을 손에 안 쥔 raw MCP의 약점. 플러그인은 34/38로 훨씬 나음. R3에서 resolve 지시 강화 예정.

## ⚠ 인프라 제약 (아침 리뷰)

창업자 API 키의 rate limit이 낮아 야간 대량 eval이 반복 throttle됨(동시성 3에도 0 산출). R4에서 페이싱(콜당 1.5s·동시성 1·시나리오 12)으로 완주 우선 전환 — 볼륨은 낮아지지만 실제 숫자를 얻는 게 먼저. '수천 케이스'는 이 키 한도가 상한. **R2~R5 4run으로 확정: 이 키는 quota 소진/하드캡 상태라 eval이 0만 냄(프로즌 67분→0=리셋되는 한도 아님).** 루프는 살아있되 자동 트리거를 멈추고 quota 리셋/새 키를 기다린다. 창업자 조치 필요: (a) 크레딧 충전/더 높은 tier 키를 ANTHROPIC_API_KEY 시크릿에 재설정, 또는 (b) quota 리셋 후 재개. 그때 페이싱 되돌리면(시나리오↑) 볼륨 회복.
