# Argus Decision Context

Argus has one domain: helping a person carry a consequential decision from the first statement through action, reality, and an earned next rule. These terms keep web, MCP, plugin, product copy, and implementation discussions semantically aligned.

## Language

**Decision Case**:
One user-owned decision and its complete history from first statement through return. A case may change state, but later events never overwrite its earlier record.
_Avoid_: Project, session, voyage

**Decision Loop**:
The closed path in which Argus helps the user understand, improve, and move a Decision Case, then returns when reality can answer.
_Avoid_: Chat, analysis pipeline, workflow

**Baseline**:
The user’s own position and reasoning captured before Argus contributes. It is evidence of the starting state, not an early decision or a score input.
_Avoid_: Initial answer, pre-seal

**Next Move**:
The action or intentional non-action the user explicitly adopts for a Decision Case. It includes decide, test, research, defer, reframe, and stop.
_Avoid_: AI recommendation, task list, next step

**Decision Record**:
The append-only, user-adopted account of a Decision Case, including authorship and provenance. AI proposals are never promoted into this record without explicit adoption.
_Avoid_: AI summary, profile, score

**Return Contract**:
The user-approved signal, event, commitment, or date that makes a Decision Case worth reopening. It is a promise to resume meaningfully, not a generic reminder.
_Avoid_: Notification, follow-up, engagement nudge

**Observation**:
What the user or a cited source reports happened after a Next Move. Observations are collected before the old record is interpreted and are appended without grading the user.
_Avoid_: Verdict, outcome score, prediction accuracy

**Return**:
The moment an Observation or promised date reopens a Decision Case so the user can compare reality with the preserved record.
_Avoid_: Reminder, re-engagement

**Lesson**:
A revocable, user-approved rule derived from one or more completed Decision Loops for reuse in a future decision. It is never an automatic personality inference.
_Avoid_: User insight, trait, profile

**Active Portfolio**:
The small set of Decision Cases currently moving, waiting for a signal, or due for Return. It creates useful continuity without manufacturing daily activity.
_Avoid_: Dashboard, backlog, engagement feed

**Surface**:
A place where the same Decision Loop is projected: web, MCP, or plugin. Capability may vary by Surface; meaning and provenance may not.
_Avoid_: Separate product, channel-specific method
