# ⚠️ Deprecated — use `argus-plugin-v2/`

This directory is the **first-generation Argus Claude Code plugin** and is no
longer maintained. It is kept only for historical reference.

The **canonical, maintained plugin is [`../argus-plugin-v2/`](../argus-plugin-v2/)**.
It is what the marketplace installs and what CI builds and tests:

```text
/plugin marketplace add commet/Argus
/plugin install argus@argus
```

Please do not build new work on `argus-plugin/`. Bug reports and pull requests
against this directory will generally be closed in favor of the v2 plugin.
