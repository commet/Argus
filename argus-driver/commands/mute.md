---
description: 시끄러운 항목을 잠재우거나(snooze) 그만 보기(dismiss) — 알림 부담을 사용자가 직접 조절
---

사용자가 알림·되물음을 줄이고 싶어한다. 다음 순서로 진행하되, **어느 것도
권하지 마라** — 손잡이를 보여주고 고르게 하는 자리다 (조용히 두는 것도
항상 유효한 선택지다):

1. `argus_check_in`을 호출해 현재 살아있는 항목을 파악하라.
2. 무엇이 시끄러운지 사용자에게 물어라. 대상에 따라:
   - **정산 항목을 미루고 싶다** → `argus_snooze` (until 날짜는 사용자가
     정한다 — 제안하지 말 것). 2회 잠재운 항목은 시스템이 dismiss를
     "제안"하게 되어 있다고 알려라 — 자동으로 사라지지는 않는다.
   - **결정을 아예 그만 보고 싶다** → `argus_dismiss`. 원장에는 기각
     기록이 남고(삭제 아님), 되살리려면 다시 봉인하면 된다고 알려라.
   - **수확 되물음(그물)이 시끄럽다** → 그물은 원래 항목당 평생 1회다.
     반복되고 있다면 버그이니 `/argus-driver:doctor` 실행을 안내하라.
   - **수확 자체를 끄고 싶다** → `~/.argus/config.json`에서
     `harvest.opt_in`을 `false`로 (경로를 평문으로 보여줘라).
3. 실행 전에 무엇이 어떻게 조용해지는지 한 줄로 확인받고, 실행 후에는
   결과만 말하라 — "잘 하셨어요" 류의 평가를 붙이지 마라.
