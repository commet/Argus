# Argus 검증 루프 — 채점 루브릭

각 표면(gallery/NN-*.png + surfaces.json[i])을 아래 3층으로 채점한다.
findings는 반드시 **진단(파일:줄 또는 프롬프트)**과 **집도안**을 함께 적는다.
막연한 "어색하다"는 finding이 아니다.

## 심각도
- **P0** 깨짐/거짓말: 기능 안 됨, 레일이 사실과 다름, 스파인 위반, 읽기 불가.
- **P1** 명백한 품질 결함: 위계 붕괴, 저품질 내용, 어색한 크기/간격, 혼란 유발.
- **P2** 다듬기: 미세 정렬·여백·톤.

## 창업자 팁 (2026-07-09)
- **긴 줄글 블록엔 굵기·색·음영으로 강조를 줄 수 있다** — 핵심 어구를 bold/색으로
  집어주면 스캔이 산다. 단 **과하면 초보처럼 보인다**: 한 단락에 한두 군데,
  의미상 하중 실린 곳에만. 문서 본문·요약·근거 같은 긴 텍스트가 대상.
- 텍스트 크기·위치는 항상 부족하기 쉬우니 매 표면에서 재확인.

## 1층 — UX (모든 표면)
1. **위계**: display 활자가 화면당 1개인가? (measures.headlines에 큰 폰트 2+개 = 냄새)
2. **가독성**: 본문 최소 폰트 ≥ 12px? (measures.minBodyFontPx) line-height 여유?
3. **크기·비중**: 주인공이 제일 크고, 조연이 작나? CTA가 시선을 끄나?
4. **간격·정렬**: 요소 정렬 축 일관? 답답하거나 붕 뜨지 않나?
5. **어포던스**: 누를 것이 눌러 보이나? 탈출구가 보이나? 죽은(안 눌리는데 눌릴 듯) UI 없나?
6. **모션·상태**: 진행/대기가 명확? 멈춘 것처럼 안 보이나?
7. **정보구조**: 한 화면에 주인공 하나. 중복(같은 말 두 번)·고아(맥락 없는 조각) 없나?

## 2층 — 내용/고도 (텍스트가 있는 표면)
8. **고도**: 너무 좁음(지엽)/너무 넓음(뻔한 일반론)/너무 얕음(수준 낮음) 중 어디에 치우쳤나?
9. **핵심 명료성**: 한 문장에 한 메시지? 복문·수식어로 흐려지지 않나?
10. **스파인**: 판정·점수·조언·재촉 없나? 저작권 정직(AI가 채운 건 ai_surfaced 태그)?
11. **목소리**: 해요체 동료, 과장·비꼼 없음, 정량 디폴트(막연한 형용사 아님).
12. **연결**: 이 표면이 앞뒤 단계와 이어지나? "그래서 뭘 하라는지" 명확?

## 3층 — 엔진 (내용 결함의 뿌리)
내용 결함(2층)을 발견하면 그 텍스트를 만든 곳을 지목한다:
- 프롬프트: `src/lib/progressive-prompts.ts` (분석·질문·믹스·사다리)
  · `src/lib/persona-prompt.ts` · `src/lib/recast-core.ts` · `reframe-core.ts`
- 파이프라인: `src/lib/progressive-engine.ts` (라우팅·수렴·단계)
- 렌더 계약: 컴포넌트가 필드를 잘못 쓰거나 잘라서 망치는가?
집도는 **프롬프트 규칙 추가/교체**거나 **파이프라인 로직**이지, UI 땜빵이 아니다.

## findings 포맷 (ledger에 append)
```
### F-<loop>-<n> · [P0|P1|P2] · <표면> · <차원#>
증상: (스크린샷/측정값에서 관찰된 것 — 숫자 포함)
진단: (파일:줄 또는 프롬프트 위치 — 왜 이렇게 나오는가)
집도: (정확히 무엇을 어떻게)
상태: open | fixed(<commit>) | wont-fix(<사유>)
```

## 루프 규율
- 한 루프에 findings 3~6개까지만 집도 (묶음이 커지면 검증이 흐려진다).
- 집도 후 반드시 재캡처로 그 표면만 확인하고 커밋.
- P0 > P1 > P2 순. 같은 심각도면 여정 앞쪽(더 많은 사용자가 봄) 우선.
- 20+ 루프: 1~8차 UX 위주, 9차부터 내용/엔진 비중↑.
