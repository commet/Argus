---REPLY---
This regex matches strings in the format of a 7-digit phone number written as **XXX-XXXX** (three digits, a hyphen, then four digits) — for example, `555-1234`.

Breaking it down:
- `^` — start of string
- `\d{3}` — exactly 3 digits
- `-` — a literal hyphen
- `\d{4}` — exactly 4 digits
- `$` — end of string

This is the classic pattern for the local/last-seven-digits portion of a US-style phone number (without area code).
