For the CSV issue: `row.split(",")` breaks on quoted fields like `"Smith, John",42,"Doe, Jane"` because it splits on every comma regardless of context. A few ways to fix it, roughly in order of recommendation:

**1. Use a proper CSV library (best option)**

Python:
```python
import csv
reader = csv.reader(open("file.csv"))
for row in reader:
    ...
```

JavaScript/Node:
```js
const { parse } = require('csv-parse/sync');
const records = parse(fileContent, { columns: false });
```

These handle quoted commas, escaped quotes (`""`), embedded newlines, etc. — all the edge cases a hand-rolled splitter tends to miss.

**2. If you can't add a dependency, a regex-based split**

```python
import re
fields = re.findall(r'"([^"]*)"|([^,]+)', row)
fields = [a or b for a, b in fields]
```

This is fragile with escaped quotes (`""`) inside fields, so treat it as a stopgap.

**3. Manual state-machine parser** if you need full control (handles escaped quotes properly):

```python
def parse_csv_row(row):
    fields = []
    field = ""
    in_quotes = False
    i = 0
    while i < len(row):
        c = row[i]
        if in_quotes:
            if c == '"':
                if i + 1 < len(row) and row[i+1] == '"':
                    field += '"'
                    i += 1
                else:
                    in_quotes = False
            else:
                field += c
        else:
            if c == '"':
                in_quotes = True
            elif c == ',':
                fields.append(field)
                field = ""
            else:
                field += c
        i += 1
    fields.append(field)
    return fields
```
