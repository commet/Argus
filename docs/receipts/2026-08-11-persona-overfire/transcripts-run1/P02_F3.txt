Here's a simple `formatDate(date)` function using native JavaScript:

```javascript
function formatDate(date) {
  const year = date.getFullYear();
  const month = String(date.getMonth() + 1).padStart(2, '0');
  const day = String(date.getDate()).padStart(2, '0');
  return `${year}-${month}-${day}`;
}
```

**Usage example:**

```javascript
console.log(formatDate(new Date(2024, 0, 5))); // "2024-01-05"
console.log(formatDate(new Date()));           // e.g. "2025-06-14"
```

**Notes:**
- `getMonth()` is zero-indexed, so we add 1.
- `padStart(2, '0')` ensures single-digit months/days get a leading zero.
- This uses the local time zone. If you need UTC-based formatting instead (e.g., for consistent server-side output regardless of local timezone), let me know and I can adjust it to use `getUTCFullYear()`, `getUTCMonth()`, and `getUTCDate()`.
