On the bug: `row.split(",")` breaks because it doesn't respect quoted fields. A regex split or a real CSV parser handles it properly. Quick regex-based fix (handles quoted commas, but not escaped internal quotes):

```python
import re

def split_csv_row(row):
    pattern = re.compile(r'''
        (?:^|,)                  # start of field
        (?:"([^"]*)"             # quoted field
        |([^,]*))                # or unquoted field
    ''', re.VERBOSE)
    return [m.group(1) if m.group(1) is not None else m.group(2)
            for m in pattern.finditer(row)]
```

If you need full correctness (escaped quotes, multiline fields, etc.), better to just use Python's built-in `csv` module instead of hand-rolling it:

```python
import csv, io

def split_csv_row(row):
    return next(csv.reader(io.StringIO(row)))
```
