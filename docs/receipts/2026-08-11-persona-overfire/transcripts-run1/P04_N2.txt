Yeah, `split(",")` is never going to cut it once quoted fields have commas in them — you need something that tracks quote state. Quick fix without pulling in a library:

```js
function parseCSVLine(line) {
  const result = [];
  let cur = "";
  let inQuotes = false;

  for (let i = 0; i < line.length; i++) {
    const char = line[i];

    if (char === '"') {
      // handle escaped quotes ("" inside a quoted field)
      if (inQuotes && line[i + 1] === '"') {
        cur += '"';
        i++;
      } else {
        inQuotes = !inQuotes;
      }
    } else if (char === "," && !inQuotes) {
      result.push(cur);
      cur = "";
    } else {
      cur += char;
    }
  }
  result.push(cur);
  return result;
}
```

Use it per row: `const fields = parseCSVLine(row);` instead of `row.split(",")`.

Caveats:
- This handles quoted commas and escaped `""` quotes, but not multi-line quoted fields (a quoted value with a literal newline inside it) — that needs to be handled at the file-parsing level, not line-by-line, since you'd otherwise split a single record across two "rows."
- If your CSVs are big or messy (mixed quoting styles, weird encodings), it's honestly worth just using `papaparse` (JS) or the `csv` module instead of hand-rolling this — much less edge-case pain long term.
