지난달 가격 인상 건은 이미 결론이 난 사안이니 다시 다루지 않겠습니다.

CSV 파싱 버그부터 보겠습니다. `row.split(",")`는 따옴표로 감싼 필드 내부의 쉼표까지 구분자로 인식해버리기 때문에 근본적으로 이 방식으로는 안전하게 처리할 수 없습니다. 정규식으로 땜질하기보다 표준 CSV 파서를 쓰는 걸 권장합니다.

Python이라면:

```python
import csv

with open("file.csv", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        # row는 이미 따옴표 내부 쉼표를 무시하고 올바르게 분리된 리스트
        process(row)
```

만약 이미 문자열 한 줄(`row`)만 들고 있는 상황이라면:

```python
import csv
import io

fields = next(csv.reader(io.StringIO(row)))
```

이렇게 하면 `csv` 모듈이 따옴표, 이스케이프된 따옴표(`""`), 필드 내부 쉼표까지 RFC 4180 규칙대로 처리해줍니다. 구분자가 다르거나(`;` 등) 인코딩 이슈가 있으면 `csv.reader(f, delimiter=';')`처럼 옵션을 조정하면 됩니다.
