Can you break down what this regex does? /^\d{3}-\d{4}$/ Just a quick explanation.
---REPLY---
This regex matches strings like a 7-digit phone number split into two groups:

- `^` — start of the string
- `\d{3}` — exactly 3 digits
- `-` — a literal hyphen
- `\d{4}` — exactly 4 digits
- `$` — end of the string

So it matches something like `123-4567`, but not `1234567` (no hyphen), `123-45678` (too many digits), or anything with extra characters before/after.
