For the CSV bug: `row.split(",")` breaks because it doesn't know about quoted fields. A quick, dependency-free fix is a small state-machine parser instead of a naive split:

```js
function parseCSVRow(row) {
  const result = [];
  let cur = "";
  let inQuotes = false;

  for (let i = 0; i < row.length; i++) {
    const char = row[i];

    if (char === '"') {
      // Handle escaped quotes ("" inside a quoted field)
      if (inQuotes && row[i + 1] === '"') {
        cur += '"';
        i++;
      } else {
        inQuotes = !inQuotes;
      }
    } else if (char === "," && !inQuotes) {
      result.push(cur);
      cur = "";
    } else {
      cur += char;
    }
  }
  result.push(cur);
  return result;
}
```

This handles:
- Commas inside quoted fields (`"Smith, John"` stays as one field)
- Escaped double quotes (`""` → `"`)

If the CSVs get more complex (multi-line quoted fields, different delimiters, etc.), it's worth switching to a battle-tested library like `papaparse` or `csv-parse` rather than maintaining a hand-rolled parser. Want me to wire one of those in instead, or is the inline parser enough for your case?
