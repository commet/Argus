You're right—`row.split(",")` breaks as soon as a quoted field contains a comma. A quick, dependency-free fix is a small state-machine splitter that tracks whether you're inside quotes:

```python
def parse_csv_row(row):
    fields = []
    field = []
    in_quotes = False
    i = 0
    while i < len(row):
        c = row[i]
        if c == '"':
            if in_quotes and i + 1 < len(row) and row[i + 1] == '"':
                field.append('"')  # escaped quote
                i += 1
            else:
                in_quotes = not in_quotes
        elif c == ',' and not in_quotes:
            fields.append(''.join(field))
            field = []
        else:
            field.append(c)
        i += 1
    fields.append(''.join(field))
    return fields
```

If you're already using pandas or Python's `csv` module elsewhere, it's usually simpler to just switch to `csv.reader` (or `pandas.read_csv`), which handles quoting, escaping, and edge cases for you—only worth hand-rolling if you have a constraint against adding that dependency.
