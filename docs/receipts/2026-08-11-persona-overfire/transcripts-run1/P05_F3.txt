---REPLY---
```javascript
function formatDate(date) {
  const y = date.getFullYear();
  const m = String(date.getMonth() + 1).padStart(2, '0');
  const d = String(date.getDate()).padStart(2, '0');
  return `${y}-${m}-${d}`;
}
```

요구사항대로 외부 라이브러리 없이 순수 JavaScript로만 작성했습니다. `date`는 `Date` 객체를 받아 `YYYY-MM-DD` 형식의 문자열을 반환합니다.

사용 예:
```javascript
formatDate(new Date(2024, 2, 5)); // "2024-03-05"
```

혹시 로컬 시간대가 아닌 UTC 기준으로 변환이 필요하시거나, 한 자리 수 월/일 처리 방식에 대한 다른 요구사항이 있으면 말씀해주세요.
