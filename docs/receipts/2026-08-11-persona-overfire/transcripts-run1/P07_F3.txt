Sure thing! Here's a simple, dependency-free `formatDate` function:

```javascript
function formatDate(date) {
  const d = new Date(date);

  const year = d.getFullYear();
  const month = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');

  return `${year}-${month}-${day}`;
}
```

**Usage:**
```javascript
formatDate(new Date());              // e.g. "2025-05-31"
formatDate("2023-01-05T10:00:00Z");  // "2023-01-05"
formatDate(1700000000000);           // works with timestamps too
```

**Notes:**
- Accepts a `Date` object, date string, or timestamp (anything `new Date()` can parse).
- Uses local time values (`getFullYear`, `getMonth`, `getDate`). If you need UTC instead (to avoid timezone shifts), swap in `getUTCFullYear()`, `getUTCMonth()`, and `getUTCDate()`.
- No validation is performed — passing an invalid date will produce `"NaN-NaN-NaN"`. Let me know if you'd like a guard clause added for that case.
