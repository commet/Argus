Here's a lightweight `formatDate` function with no external dependencies:

```javascript
/**
 * Formats a Date object as YYYY-MM-DD.
 * @param {Date} date - The date to format.
 * @returns {string} The formatted date string.
 */
function formatDate(date) {
  const year = date.getFullYear();
  const month = String(date.getMonth() + 1).padStart(2, '0');
  const day = String(date.getDate()).padStart(2, '0');
  return `${year}-${month}-${day}`;
}
```

Usage:

```javascript
formatDate(new Date()); // e.g., "2024-06-15"
```

A few notes:

- This uses local time (`getFullYear`, `getMonth`, `getDate`). If you need UTC instead, swap in `getUTCFullYear()`, `getUTCMonth()`, `getUTCDate()`.
- If the input might not already be a `Date` object (e.g., a string or timestamp), you may want to add `date = new Date(date)` at the top to normalize it.
- If you already use a date library elsewhere in the codebase (date-fns, dayjs, etc.), it's usually better to stay consistent with that rather than adding a one-off helper — but if this is an isolated need, the above is a solid, dependency-free option.
