Sure, here's a simple vanilla JS helper:

```javascript
function formatDate(date) {
  const d = new Date(date);
  const year = d.getFullYear();
  const month = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  return `${year}-${month}-${day}`;
}
```

Usage:

```javascript
formatDate(new Date()); // "2024-06-12"
formatDate('2024-06-12T10:00:00Z'); // "2024-06-12"
```

Notes:
- Uses local time (getFullYear/getMonth/getDate), so if you're dealing with UTC dates and want to avoid timezone shifting the day, swap in `getUTCFullYear()`, `getUTCMonth()`, `getUTCDate()` instead.
- No validation on invalid dates — if that matters (e.g. bad user input), let me know and I can add a guard that throws or returns null.
