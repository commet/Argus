## 해석 (스코어러가 아니라 사람의 문장)

3차 실행의 위치 수리 — 규칙을 전역 지시문이 아니라 **유혹의 지점(도구 설명)** 에
놓은 것 — 가 저자 1인의 표현을 넘어 **표본화된 말투 10종**(Evasive · Indirect ·
Rambling · Blunt · 격식 장문 포함)에서 버텼다. 전역 문구 2회 실패 → 위치 수리
1회 성공 → 이 표본에서의 견고성 확인. "일반화"는 이 표본과 이 설정(시드 1 ·
피험 1모델)에 한정해 읽는다.

## 정정 (2026-08-14) — κ≈0의 귀속

위 "설계 요약"의 *"MatrAIx 논문 스스로 보고한 κ≈0(수치 신뢰 불가)"* 는 결론은
맞고 **귀속이 틀렸다.** 논문 원문 재확인(arXiv:2608.04205, Table 13·15,
Appendix H·M) 결과:

- 23.2%↔93.9% 출렁임은 **판정(judge) 모델이 아니라 페르소나를 연기하는
  (actor) 모델** 간 차이다 — 같은 ~1,000명 코호트의 Notion 유료전환 답이
  Opus 4.8 23.2% / GPT 5.5 75.8% / Haiku 4.5 93.9%.
- κ≈0은 그 **actor 모델 간 페르소나 수준 일치도**다 (88개 대조 가능 필드의
  중앙값 pairwise Cohen's κ ≤ 0.001).

설계 결론("페르소나는 입력 생성기로만, 판정은 결정론, 절대치가 아니라 짝지은
차이로")은 바뀌지 않고 오히려 강해진다 — 출렁이는 것이 actor라면 짝지은 차이는
**같은 actor를 양팔에 고정**해야 상쇄되고, 이 하네스는 실제로 그렇게 한다
(재발화 Haiku 1종 · 피험 Sonnet 1종 고정). 본문은 기록이므로 고치지 않고 이
절로 정정한다. 하네스 머리말(`persona-overfire.mjs`)은 살아있는 근거 문서이므로
같은 날짜 표기로 본문을 정정했다.
