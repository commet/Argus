## v4 반영 목록 (전부 반영됨 — v4 개정 커밋 참조)

1. **감지기 수리 동사 신설**: 경보·차단 화면에 [오탐 — 깎기] · `amend`(감지

   (L3 비상 정지 — 기록되는 우회, 사후 감사) · **신규 법 72시간 관찰 모드**
   (경보 대신 기록 → "3일간 4번 걸렸다, 깎을까?"로 회귀).
2. **만기 필수의 정밀화**: 재확인 조건 필수 = 달력 **또는 사건**. 영구형
   (ban·pin)은 사건 재확인(위반·오탐 축적 시에만 묻기) — "pkill 금지 90일
   심문" 해소, "신선도는 마찰로" 원칙과 정합.
3. **역이식 후 원본 처분 명세**: CLAUDE.md → 컴파일 산출물 전환. 서명분은
   장부가 주입(원본에서 제거 — 이중 주입 해소), **미서명 후보는 원문 그대로
   잔존(효력 유지 — 강등 없음)**.
4. **온보딩 비용 정직화**: 60초 = 데모, 입법은 별도(예고 문구) + 온보딩
   버스트 완충(오늘 3건만, 나머지는 아침마다 2~3건씩).
5. **주입-전용 법 클래스**: 컴파일 불가(의미론) 규칙은 감시 없음 정직 표기로
   서명 — 제일 아픈 규칙이 컴파일 안 되는 문제의 정직한 처분.
6. **빈손 분기**: git 커밋 이력에서 암묵 결정 역추출 + review 기본 지평

7. **서명의 정의 강화** (시장 승인 6종과의 차이 3조건): 승인 행위 자체가

**2차의 공통 뿌리 (1차가 "서명 후 수리 동선 부재"였다면)**: v4의 문법 전체가
**"한 사람이, 자격을 갖추고, 깨어서, 화면 앞에 있다"**는 단수·재석 가정 위에
있었다. 사람이 둘이거나(P4), 전제가 없거나(P5), 자리에 없으면(P6) 무너진다.

**v4 반영 — 처방 7** (§4 "단수·재석 가정을 푼다" 절): ① author 필수 필드 +
정직 카피 ② 수신 1비트 `binds: author|repo` + 수신 서명 ③ 타인 법 이의 동사
`object` ④ **무인 기본값을 서명 필드로** (`unattended: park|log|deny` — 서명의
대리가 아니라 사전 확장, 불변식 ② 무저촉; pause는 영원히 사람 전용 명문화)
⑤ 함대 집계층(사건 병합·후보 중복 합치기·배치 부검·**후보에도 만기**) ⑥ 장부
단일 진실 위치(워크트리 독립) + 긴급 ban 즉시 발효 옵션 ⑦ init의 자격 판정과
정직한 거절. 배치: ①④⑥⑦은 시공 2주 안(값쌈), ②③⑤는 관문 1 뒤.
+ 창업자 판정 사항 등재: 서명 표면의 해석(불변식 ②의 핵이 '사람 전용'인가
'TTY 기제'인가 — P5의 미래가 여기 걸림).

**P6가 준 반증 불가한 응원 하나**: 정산의 교훈 한 줄이 다음 밤 봇의 행동을
실제로 바꾼 순간 — §1 "정산의 소비자는 내일 아침의 에이전트"가 시뮬 6개를
통틀어 처음 현금화된 장면.
