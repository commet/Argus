## v4 반영 목록 (전부 반영됨 — v4 개정 커밋 참조)

1. **감지기 수리 동사 신설**: 경보·차단 화면에 [오탐 — 깎기] · `amend`(감지
   규칙만 좁히는 개정 이벤트 — 결정 문장 불변, 불변식 ③ 충족) · `pause`
   (L3 비상 정지 — 기록되는 우회, 사후 감사) · **신규 법 72시간 관찰 모드**
   (경보 대신 기록 → "3일간 4번 걸렸다, 깎을까?"로 회귀).
2. **만기 필수의 정밀화**: 재확인 조건 필수 = 달력 **또는 사건**. 영구형
   (ban·pin)은 사건 재확인(위반·오탐 축적 시에만 묻기) — "pkill 금지 90일
   심문" 해소, "신선도는 마찰로" 원칙과 정합.
3. **역이식 후 원본 처분 명세**: CLAUDE.md → 컴파일 산출물 전환. 서명분은
   장부가 주입(원본에서 제거 — 이중 주입 해소), **미서명 후보는 원문 그대로
   잔존(효력 유지 — 강등 없음)**.
4. **온보딩 비용 정직화**: 60초 = 데모, 입법은 별도(예고 문구) + 온보딩
   버스트 완충(오늘 3건만, 나머지는 아침마다 2~3건씩).
5. **주입-전용 법 클래스**: 컴파일 불가(의미론) 규칙은 감시 없음 정직 표기로
   서명 — 제일 아픈 규칙이 컴파일 안 되는 문제의 정직한 처분.
6. **빈손 분기**: git 커밋 이력에서 암묵 결정 역추출 + review 기본 지평
   (+7일 제안) + 첫 만기 1건을 1주 안에 설계 — L5를 이탈 전에 보여준다.
7. **서명의 정의 강화** (시장 승인 6종과의 차이 3조건): 승인 행위 자체가
   이벤트로 기록되고 · scope/만기/철회가 결박되고 · fail-closed.
8. 기타: ≤15 선발 규칙 명세 · 기존 가드(테스트·훅) 인식과 중복 병합 ·
   개인 장부 모드(팀 repo 솔로) · 인용 5조(팀 가시 산출물엔 기본 미표시) ·
   git 채널 사후 경보의 시점·형태 · 관문 2 대상 ICP 명시(Claude Code 주
   사용) · §9 경쟁 표 갱신(Cupcake·claude-reflect·CodeRabbit·fan-out 방출
   전략) · §5 시운전 행 정정(claude-reflect 근접 사례) · **시공 리듬에 여정

## 2차 시뮬 (같은 날 오후 — 창업자 지시 "새로운 유형의 사람과 케이스")

| 배역 | 이탈 | 직접 사인 |
|---|---|---|
| P4 2인 공동창업 팀 | 민서 Day 13 전량 · 지호 Day 8 부분 | **법의 수신 모델 부재** — 서명(발신)은 정밀한데 같은 repo의 타인이 왜 그 법에 통치받는지 0줄. "네 결정" 카피가 남의 법에 저자성 거짓말. 이의 동사 부재로 조정이 전부 Slack으로 |
| P5 터미널 없는 지식노동자 | 설치 단계 (걸음 2~4) | **자격 판정·정직한 거절 부재** — 전제 물자 0/6인 사람이 문 앞에서 헤맴. 판정: 지금 시장 아님(명세가 이미 그은 경계의 실물), 단 "거절도 설계돼야 거절이다" |
| P6 에이전트 함대 운영자 | Day 12 집행층 이탈 | **무인 시간의 의미론 부재** — 경보 동사 넷이 전부 사람 손, 무인 기본값이 암묵 [계속](아무도 서명 안 한 정책). "병목은 원래 나였고 장부는 계량만 했다 — 병목을 견딜 사무 장비를 안 줬다" |

**2차의 공통 뿌리 (1차가 "서명 후 수리 동선 부재"였다면)**: v4의 문법 전체가
**"한 사람이, 자격을 갖추고, 깨어서, 화면 앞에 있다"**는 단수·재석 가정 위에
있었다. 사람이 둘이거나(P4), 전제가 없거나(P5), 자리에 없으면(P6) 무너진다.

**v4 반영 — 처방 7** (§4 "단수·재석 가정을 푼다" 절): ① author 필수 필드 +
정직 카피 ② 수신 1비트 `binds: author|repo` + 수신 서명 ③ 타인 법 이의 동사
`object` ④ **무인 기본값을 서명 필드로** (`unattended: park|log|deny` — 서명의
대리가 아니라 사전 확장, 불변식 ② 무저촉; pause는 영원히 사람 전용 명문화)
⑤ 함대 집계층(사건 병합·후보 중복 합치기·배치 부검·**후보에도 만기**) ⑥ 장부
단일 진실 위치(워크트리 독립) + 긴급 ban 즉시 발효 옵션 ⑦ init의 자격 판정과
정직한 거절. 배치: ①④⑥⑦은 시공 2주 안(값쌈), ②③⑤는 관문 1 뒤.
+ 창업자 판정 사항 등재: 서명 표면의 해석(불변식 ②의 핵이 '사람 전용'인가
'TTY 기제'인가 — P5의 미래가 여기 걸림).

**P6가 준 반증 불가한 응원 하나**: 정산의 교훈 한 줄이 다음 밤 봇의 행동을
실제로 바꾼 순간 — §1 "정산의 소비자는 내일 아침의 에이전트"가 시뮬 6개를
통틀어 처음 현금화된 장면.

## 3차 시뮬 (같은 날 — 창업자 지시 "다른 방향성으로, 진짜 놓치는 것 없도록")

1·2차가 **한 사람의 2주**를 시험했다면 3차는 **집합·공개·악의·출구**를
시험했다. 축이 겹치지 않도록 넷을 골랐다.

| 배역 | 판정 | 최대 발견 |
|---|---|---|
| **P7 6개월 누적** | 이탈 안 함 — 단 **아슬아슬한 생존, 교환식 대략 본전** | **명세는 결정 하나의 생애를 훌륭히 닫았고 결정들의 집합을 설계하지 않았다.** 만기 전 은퇴 동선 부재(피벗 31건 폐지 = 2시간) · 주입 ≤15 선정 규칙 부재(조용한 좋은 법이 굶어서 은퇴 후보가 되는 루프 + **주입 안 된 75건의 훅은 살아 있다**) · 30일 보존 vs 90일 만기의 산술 불일치("이유를 모르는 채 90일 연장했다") · 사후 모순 감사 부재 · **살린 것은 L5와 빈티지 고정**("시간을 벌어주지 않았다, 되짚을 수 있게 해줬다") |
| **P8 오픈소스** | 이탈 안 함 — **명세가 준 것의 절반만 씀** | **무채점 불변식이 공개 환경에서 포인터 역참조로 우회된다** — 제품은 집계 안 해도 GitHub이 SHA→저자 join을 공짜로 해준다("사람 이름 붙은 위반 기록을 공개하는 메인테이너가 된다") → **첫 주에 최고 기능(집행 기록)을 스스로 껐다.** 붙잡은 것은 서명·정산이 아니라 **"인용 가능한 정본 + 열린 포맷"**. 유통 실험 3은 **숙주를 바꾸면 유효**(우리 리포엔 사전 독자가 0, 메인테이너 리포엔 월 15~30명) |
| **P9 오용·회피·감시** | — (안전성 시뮬) | **불변식 8 중 5개 뚫림.** ①(평문)이 ②(대리 불가)를 무력화하고 ⑧(무채점)과 충돌 · ④가 감시 원재료를 영속시킴 · **관문에 상한이 없어 y 연타가 최적 전략** · `amend` 주체 미규정(에이전트가 감지를 끌 수 있다) · **오귀속은 벤더보다 나빠진다**(`author`가 서명자라 AI 후보에 서명하면 사용자 저작이라 주장) · "작동은 정직에 의존하고, 부정직은 기록되지만, **그 기록을 읽는 사람이 없다 — 읽는 사람이 생기는 순간이 감시다**" |
| **P10 떠남·사후** | — | **"떠날 자유" = 현 명세로는 거짓.** 이탈 동사 0(입구는 둘, 출구는 0) · 컴파일 전환이 단방향이라 **떠나면 규칙 파일이 설치 전보다 나쁨** · **스펙 공개가 관문 3 뒤인데 기각 경로 8개는 전부 그 앞** = 가장 확률 높은 사망에서 공개가 안 일어남 · 좀비 설치가 **우리가 고치겠다던 병(무신호 낡음)을 제조** · 해법 하나가 **5줄**(원문을 `source`에 보관) |

**3차의 공통 뿌리**: 1차 = 서명 후 수리 동선 부재 / 2차 = 단수·재석 가정 /
**3차 = 결정 하나는 닫혔는데 결정들의 집합·제도의 출구·악의의 압력이
설계되지 않았다.**

**v4 반영 — §4-b 처방 아홉 + 함께 고친 다섯** (전부 반영·커밋됨):
값싼 넷(2주 안) = ①**원문 보존(≈5줄, 가장 크다)** ②`dec leave`+설치 인벤토리
③`sunset`(범위 폐지) ④좀비 감쇠. 구조 다섯(관문 1 전후) = ⑤서명 봉인+`verify`
⑥`amend`를 pause 등급으로+영향평가+사건형 감지 0이면 자동 달력 만기
⑦`provenance` 필수(발원≠서명) ⑧`dec review <pr>`(대조 대상 확장 — CI에서
돌리면 그게 L4) ⑨`dec audit`(집합의 위생, 감사=셋째 시점). 함께: ⓐ주입을
배급→회전 ⓑ주입 안 된 법의 훅 발화 시 원문 표시 ⓒ만기 걸린 결정은 근거 즉시
승격 ⓓ공개 가시성 필드 단위+불변식 ⑧ 공개판 한 줄 ⓔ정산에 "뭘 막았나" 입력구.
관문 1에 **채택률 상한 ≤70%** 신설, §8에 **감사/채점 경계** 정의.

**창업자 판정 사항 3건 등재** (§11): ②의 핵이 사람인가 TTY인가(P5) ·
**⑧은 약속인가 불변식인가**(P9 — 기판으로 내리려면 ④와 관문 4 계측을 깨야
하는 교환) · **사후 조항**(P10 — 라이선스 명기 + §10 각 항에 "발동 시 스펙
