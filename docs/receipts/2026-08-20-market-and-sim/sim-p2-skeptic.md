# 여정 시뮬 P2 — 회의적 시니어의 2주 (저밀도·Cursor 혼용·팀 repo 솔로)

> 배역: 12년차, TS 120k LOC 팀 4명 repo, Cursor/Claude Code 반반, 규칙 23줄
> 보유, 결정 주 2~3건, 3일 안에 가치 없으면 지움. 명세는 v4 §3·§4만.

## 요약 타임라인

- **Day 0**: init+rehearse는 진짜 60초 — "23건 중 5건 부딪힘, 3건 실제 위반,
  최다: console.log 금지 4번". 단 4번 중 2번은 **지우라고 시킨** 세션(언급≠위반).
  서명은 건당 60~90초 컴파일 확인 — 6건 서명에 25분. 전례 소환이 중복 3쌍
  (pnpm·any·zod)을 잡아줌. **"pnpm만 쓴다"에 만기 90일 강제 — 11월에 심문 6건
  예약된 셈.**
- **Day 1**: 서명 6건이 L1 주입 + 원본 CLAUDE.md 병존 = **이중 주입.**
  `decisions/` 7파일이 untracked — 팀 repo에 개인 장부 커밋? → gitignore →
  "git이 역사·동기화 담당"(§4) 반쪽 사망. 저녁 후보 1건(tanstack v4 고정)은
  수집 정확·서명 — 이건 만기가 자연스러운 종류.
- **Day 2**: npm install을 훅이 실제 차단(진짜 1승). 오후 console.log **정리**
  작업에 경보 — 오탐 1.
- **Day 5 (Cursor 날)**: 어댑터 없음 — 주입도 수집도 없음. **이번 주 진짜 결정
  ("zustand 유지, jotai 안 감")이 장부 밖에서 발생.** 오후 커밋의 위반(default
  export)은 **다음날** git diff 채널이 사후 경보 — 이미 push 뒤. "맞는 말을
  늦게 하는 건 문지기가 아니라 잔소리."
- **Day 7**: 에이전트가 PR 본문에 "D-0004에 따라…" — **팀원: "D-0004가 뭐야?"**
  혼자 쓰는 도구의 좌표가 팀 산출물에. 손으로 지움.
- **Day 8**: 오탐 3회째 [계속] → 제품이 묻는다: "이 법, 아직 유효한가?
  [중요도 하락/시간 없음/이미 정산됨/재우기]" — **넷 다 내 귀책. '감지기가
  틀렸다'는 없다.** 서명 후 깎는 명령 부재. [재우기].
- **Day 9**: 세션이 산으로 감 — 그 규칙은 미서명 17건 중 하나라 경보 0.
  autopsy는 갈림길을 정확히 짚고 후보 2 제안 — 진단 맞음, 서명 안 함(컴파일
  검토 통행료 재차 지불 거부).
- **Day 3~4·10~12 (조용한 날들)**: 후보 0·경보 0·만기 0 — 침묵은 옳은 설계나
  **침묵하는 동안 존재 이유도 침묵.** "2.3건/일"은 창업자 밀도 — 내 14일 자동
  수집 후보 총 2건(서명 1). 만기는 전부 11월 — **정산 0회.**
- **Day 13**: Cursor에서 또 결정("모노레포 안 감") — 역시 장부 밖.

주입 토큰. 받은 것: 진짜 차단 1·사후 경보 1(push 뒤)·부검 진단 1(미소비)·인용
(팀에겐 소음)·정산 0. **"유일한 층"(L5)은 내 결정 빈도와 만기 기본값으로는
설치 70일 뒤 — 3일 룰인 나는 그 전에 없다.** L3 훅은 동작했지만 settings.json
몇 줄로 손으로도 씀 — 자동 컴파일의 값은 곱해질 개수인데 내 금지형은 6개.
**believe-all 역설: 절제(6/23 서명)하면 구멍(라우터 사고 무경보), 성실(전량)
하면 클릭랩 — 어느 쪽도 사용자가 이기는 판이 아님.** 주입·경보·훅 전부 제거.
`decisions/` 7파일은 무해해서 방치 — "도구는 죽었는데 시체가 무해하다는 것,
그게 이 제품 미덕의 정확한 크기."

깔았으니). 못 참은 건 제품이 자기 오탐 3번을 근거로 **내 법의 유효성을 심문**

안 읽는 경보기는 없는 경보기다. 기계적 제거는 Day 14지만 제품은 Day 8에 죽었다.
