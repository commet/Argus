# 공정 5 재실사 — 프로덕션 실주행 기록 (2026-07-28)

BLUEPRINT §6 공정 5의 exit 1 (`같은 시나리오 재실사에서 7건 육안 확인 — 창업자
또는 Playwright 캡처 3화면`)에 대한 증거다. **창업자 육안이 아니라 Playwright
실주행**으로 수행했고, exit 문구가 그 대안을 명시적으로 허용한다.

- 대상: `https://argus.voyage/ko/workspace` (프로덕션, 배포본)
- 방식: Playwright, 1440×900 데스크톱 + 390×844 모바일, 익명 세션
- 시나리오: "계약직 개발자를 정규직으로 전환할지" — 기준점 → 3문답 → 초안 →
  검토 → 봉인까지 **중단 없이 완주**
- 콘솔 에러: **0건** (`browser_console_messages(level=error)`)

캡처 원본은 커밋하지 않는다 — 리포 루트 `*.png`는 `.gitignore`가 시각-QA
스크래치로 이미 배제하고 있고(줄 50~51), 그 정책을 이 기록 때문에 뒤집지 않는다.
아래 관찰은 캡처와 DOM 측정에서 나온 것이며, 재현 절차를 함께 적어 다시 찍을 수
있게 했다.

## 3. 화면 너머 — 데이터가 실제로 도착했나

"UI가 멀쩡한 것과 데이터가 도착한 것은 다른 사실"(CLAUDE.md Persistence
Declaration 3항)이므로 봉인 뒤 실DB를 직접 조회했다.

- `projects.decision_contract` 도착. `predicates` 4건.
- **출처가 정직하다**: 사용자 문장은 `authored:"user"` /
  `wording_source:"user_direct"` / `authority:"user_asserted"`, AI 문장은
  `ai_surfaced` / `ai_suggested`. 승격 없음.
- **대표 체크포인트가 사용자 것이다**: `primary_checkpoint.authorship`
  = `"user_authored"`, `predicate_id`가 사용자 문장을 가리킴 (구현 보고서 §12
  불변식 5).
- `judgment_receipt`에 `baseline_judgment`(검토 전)와 `human_judgment`(검토 뒤)가
  **분리 보존**.

## 4. 귀환 루프가 실제로 발화하나

cron(`/api/cron/checkin-due`)이 읽는 자리가 정확히 `projects.decision_contract`임을
확인한 뒤, **프로덕션에서 꺼낸 실제 계약**에 **실제 판정 함수**를 시점만 바꿔 돌렸다:

| 시점 | `isCheckInReminderDue` |
|---|---|
| 확인일 하루 전 | `false` |
| 확인일 | `true` |
| 확인일 다음 날 | `true` |

그리고 `selectOpenPredicate`가 돌려주는 문장은 **사용자가 쓴 문장**이었다.

판정이 타임스탬프가 아니라 **로컬 날짜 단위**라는 것도 이 과정에서 확인했다
(`decision-contract.ts` 주석: 타임스탬프 비교는 "8월 4일에 물어볼게요"를 그날
정각까지 거짓말로 만든다). 첫 시도에서 "확인일 1분 전 = 미도래"를 기대한 것은
**검증자의 가정 오류**였지 제품 결함이 아니었다.

## 5. 같은 주행에서 함께 확인된 것 (공정 5 밖)

- **심층 판단이 프로덕션에서 살아났다.** 오늘 적용한 마이그레이션 뒤
  `POST /api/deep-judgment/authorize`가 `200 granted` → 같은 세션 `resumed` →
  다른 세션 `429 daily_used`. 워크스페이스에도 진입 카드가 실제로 렌더된다.
- **계정 삭제 루프가 완주 가능한 상태다.** 삭제가 도는 48개 테이블 전부에 같은
  `WHERE user_id` 쿼리를 실행 → 누락 0건. 같은 검사에 가짜 테이블을 섞으면 그것을
  정확히 지목하므로 검출기가 살아 있음도 확인했다.
- **주행 잔재는 프로덕션에서 전량 삭제했다** (projects·decision_items·
  progressive_sessions·quality_signals·rate_limits·user_events·쿼터 행 모두 0).
