# 판별 실험 G — 에이전트의 아르고스 (재정초 브리프 §4 G)

> 정본: `ARGUS-REFOUNDATION-BRIEF-2026-08-16` §4 G · §5.2.
> 브리프의 실험 정의 그대로: *"이 저장소 자체에서 도그푸드. 에이전트가
> 세션마다 하중 가정 3개를 봉인하고, 기존 훅·CI가 가정 위반 시 귀환을
> 강제한다. 측정: 조용한 오답이 시끄러운 귀환으로 전환된 건수."*

## 무엇을 지었나

| 파일 | 무엇 |
|---|---|
| `argus-agent.mjs` | 가정 봉인·검사 장치. 검사기 5종(`uploads_referenced`·`cmd_exit_zero`·`file_exists`·`zone_purity`·`branch_synced`) |
| `assumptions-standing.json` | 세션 무관 상시 가정 3건 (훅이 매 세션 검사) |
| `assumptions-session-898aeece.json` | 이 세션의 하중 가정 4건 |
| `session-guard.sh` | SessionStart 훅 — 위반을 세션 문맥 맨 앞에 밀어넣는다 |
| `ledger/*.jsonl` | append-only 가정 원장 (P1 빈티지 보존) |

설계 규칙 하나가 나머지를 결정했다: **가정은 기계 가독 술어여야 한다.**
산문 가정은 검사할 수 없고, 검사할 수 없는 가정은 봉인이 아니라 메모다.
그래서 `seal`은 `check`가 없는 가정을 **거부한다**(exit 2). 이것이 P5(시끄러운
실패)를 가정 층위에 적용한 형태다.

훅이 세션을 죽이지 않는 이유: 죽이면 사람이 훅을 끈다. 시끄럽되 치명적이지
않게 — 위반을 문맥 맨 앞에 놓아 에이전트가 못 본 척할 수 없게 만든다.
(M7 채택 마찰: 훅의 상시 비용은 위반 없을 때 출력 0줄이다.)

## 측정 — 조용한 오답이 시끄러운 귀환으로 전환된 건수: **1**

시험 사례는 지어낸 것이 아니라 **이 세션이 실제로 저지른 실패**다. 창업자가
2026-08-15T17:06에 재정초 브리프를 업로드했는데, 세션은 그 문서를 열지 않고
이전 세션이 만든 파생 태스크 목록만 보고 E-0을 수행했다 (E-0 리시트 §5.6).

가정 `S1-업로드된-정본을-읽었는가`를 세 시점에 검사한 결과:

| 검사 시점 | 상태 | 결과 |
|---|---|---|
| `ae5a018d` (E-0 착수 직전, 브리프는 이미 업로드됨) | **위반** | 착수 전에 울렸을 것 |
| `4dbcb8a5` (결함 있는 최초 E-0 리시트 커밋) | **위반** | 커밋 시점에도 울렸을 것 |
| `HEAD` (브리프를 읽고 반영한 뒤) | 유지 | 조용 |

그리고 이것이 핵심인데 — **그 시점에 실제로 돌던 어떤 게이트도 울리지 않았다.**
`npm test`(276개 가드 테스트), `npx tsc`, `npm run lint`, CI의 check 잡 전부
초록이었고 PR #396도 CI 전 항목 초록으로 통과했다. 결함은 코드가 아니라
**전제**에 있었고, 전제를 검사하는 장치가 없었기 때문이다. 브리프 §4 G가
"자신 있고 그럴듯하고 약간 틀린 상태"라 부른 것의 교과서적 사례다.

### 위양성도 기록한다 (장치 자신의 결함)

첫 판의 `uploads_referenced`는 문자열 그대로 대조해서 **위양성**을 냈다 —
리시트가 문서를 `ARGUS-REFOUNDATION-BRIEF-2026-08-16`(하이픈)으로 참조하는데
업로드 파일명은 `ARGUSREFOUNDATIONBRIEF20260816`(붙임)이라 못 맞췄다. 양쪽에서
영숫자만 남기는 정규화로 고쳤다. 남기는 이유: **시끄러운 실패 장치가 시끄럽게
틀리면 사람이 장치를 끈다.** 위양성률은 이 원형의 생존 조건이지 부수적 품질이
아니다.

### 훅 작동 실증

```
$ CLAUDE_UPLOADS_ROOT=/tmp/fake-uploads bash session-guard.sh
════════════════════════════════════════════════════════════
  하중 가정 위반 — 진행 전에 이것부터 처리한다
════════════════════════════════════════════════════════════
위반 · S1-업로드된-정본을-읽었는가
     검사: uploads_referenced → 업로드된 정본이 산출물에서 한 번도 참조되지
           않음: deadbeef-NEVERREFERENCEDCANON20260816.md
     귀환: 업로드된 정본을 먼저 읽는다. 파생 목록으로 작업을 시작하지 않는다.
```

위반 없을 때는 출력 0줄. 훅은 `.claude/settings.json`의 `SessionStart`에
설치했으므로 이 저장소의 **다음 세션부터 실제로 돈다** — 시연이 아니라 가동.

## 한계 (이 실험이 주장하지 않는 것)

1. **사후 설계 편향이 가장 큰 한계다.** 나는 실패를 **알고 난 뒤** 그 실패를
   잡는 검사기를 만들었다. 이 실험이 보인 것은 "이 실패 부류가 기계로 검사
   가능하다"이지 "검사기를 미리 설계했을 것이다"가 아니다. 전자만으로도
   원형 G의 존재 이유는 되지만, 효과 크기의 증거는 아니다.
2. **n=1, 1개 저장소, 실사용 0일.** 브리프는 1주 도그푸드를 요구했다. 여기
   있는 것은 장치와 과거 상태 대조뿐이다. 진짜 측정은 훅이 켜진 채로 다음
   세션들이 돌아야 나온다 — 그때 볼 것은 **위반 적중률과 위양성률의 비**다.
3. **검사 가능한 가정만 커버한다.** "내가 창업자의 의도를 이해했다" 같은
   가정은 술어로 쓸 수 없다. 이 원형이 커버하는 것은 하중 가정의 부분집합이며,
   그 경계를 넓히려는 유혹이 곧 위양성의 원천이다.
4. **자기 참조.** 이 실험을 수행한 에이전트가 이 실험의 피험자다. 브리프
   §1.2의 "루프 안의 관찰자에게는 완결 이론이 성립하지 않는다"가 그대로 적용된다.
