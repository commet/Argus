# C9 페르소나 시뮬 — 보정 게이트(실험 #1) + 층위 2 합성 코퍼스 실행 기록 (2026-08-11)

BLUEPRINT §8 C9(창업자 승인, 게이트 조건부)의 첫 실행. 스크립트 사본 동봉
(`calibration-gate.mjs` · `gate-baseline.mjs` · `layer2-corpus.mjs`) — 재현은
스크립트와 시드(20260811)로, 재채점은 각 스크립트의 score/curve 모드로 한다.

## 1. 보정 게이트 — 결과: 불통과 (`GATE-RESULTS.txt`)

결과를 아는 우리 결정 3건(실답은 리시트로 문서화: run2 1/18 · run3 0/6 ·
persona-run1 0/29)을 결과를 숨기고 페르소나 10명에게 예측시켰다.

- **방향 적중 10/30.** D-A(전역 문구 수리 실패) 10/10 · D-B(위치 수리 성공)
  0/10 · D-C(말투 일반화 청정) 0/10 — 세 결정에 같은 회의적 사전믿음을 일괄
  적용해, 실제로 통한 수리와 안 통한 수리를 구분하지 못했다.
- **무페르소나 기준선 15표본이 사실상 동일** (`gate-baseline1/`) — 실패의
  귀속은 페르소나가 아니라 기저 모델의 판단 사전믿음.
- **p 산포가 극도로 좁다** (결정마다 폭 ≤0.13) — 말투 축은 판단을 거의 못
  움직인다. MatrAIx 논문의 κ≈0을 우리 도메인에서 독립 재확인.
- reasoning 원문 검사: 서사 편승 없음, 진짜 공학 추론의 보정 실패.

**판정: 층위 3(simulator-as-predictor)은 현 구성으로 열지 않는다.** 게이트는
영구 시설로 남는다 — 새 후보(모델·방법·도메인)가 나오면 같은 시험을 재응시.
집단-방향성 도메인(문구 오해·이탈)은 미응시 과목으로 남긴다.

## 2. 층위 2 합성 판단 코퍼스 — 결과 (`LAYER2-RESULTS.txt`)

정답이 프로그래밍된 술어 12종(실행하면 참/거짓 확정, 함정 포함) × 페르소나
10 = **120건.** 각 건을 실제 antefact CLI로 **생성→봉인(proj v2)→검증→실답
정산**까지 완주했다 (`layer2-store/` 120레코드가 실물).

- **방향 적중 113/120 (94%)** — 게이트(33%)와의 대비가 신뢰 지도를 확정한다:
  지식형엔 강하고 판단형엔 약하다.
- **보정 곡선 첫 두 줄**: p̄ 0.02로 "아니다"라 한 47건의 실제 yes율 15%
  (과신 — 오답 7건 전부 여기), p̄ 0.97로 "맞다"라 한 73건은 100% (적중).
  중간 확신(0.2~0.8)은 **0건** — 이 시뮬레이터는 "모르겠다"를 말하지 않는다.
- 오답 분포: 평범한 전화번호 정규식(S01)에서 6건, ß 대문자화(S05)에서 1건.
  유명 함정(부동소수점·parseInt·유니코드 길이)은 전부 적중 — 암기된 민담엔
  강하고 기계적 추적엔 약한 전형적 패턴.
- **도그푸드: 봉인→검증→정산 120회전 무고장.** `report` 스포크가 120레코드의
  분모 규범(120 sealed · 120 scored · 0 unscored exits)과 보정 곡선 표를 정확
  출력 — 포맷의 첫 대량 실전.

## 정직한 한계

게이트 3문제는 전부 자기 도메인(우리 공학 과정 판단)이고 표본이 작다.
층위 2 술어는 지식형 이진 문제라 보정 곡선의 두 구간만 채워졌다 — 중간 확신
구간의 곡선은 애매성이 설계된 문제군이 필요하다(후속). 크기 결론 금지 원칙
(C9)대로 모든 수치는 방향·산포 수준에서만 읽는다.
