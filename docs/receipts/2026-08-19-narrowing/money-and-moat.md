## RSS 함정의 답

RSS 는 표준이 되고도 죽었다 — 구독 그래프(신원)와 서버를 아무도 안 쥐어서.
git 은 열려 있어도 GitHub 이 신원·협업·발견을 쥐었다. **포맷 위에서 돈이 되는
층: ①상태 조정(동기화) ②신원·평판 ③조직 정책·감사 ④발견.** 우리가 쥘 것 =
**결정 장부들이 만나는 지점** (팀 동기화 · CI 관문 · 공유 주소). 포맷 채택을
어댑터로 벌면서 조정층을 남보다 먼저 세운다.
