> 정산된다")를 확정하기 전의 검증. 창업자가 4트랙 전량을 선택했고, 외부 리서치

## 다섯이 합쳐져 나온 그림 (개별 보고서엔 없는 것)

1. **서 있을 땅이 확정됐다**: 채택(누가 정했나) · 재확인(현실이 바뀌었나) ·
   정산(맞았나). 셋 다 모델이 좋아져도 남고(1a), 벤더 지표가 겨냥하지 않고(1a),
   과거 무덤의 사인을 피해 가는 좁은 문(개인+즉시 효용+무징벌)과 정합한다(1b).
   **입구(위반의 분노)는 지금 뜨겁지만 ~2-3년짜리 입구다 — 제품은 입구에서
   땅으로 사용자를 옮겨야 한다.**
2. **서명은 마찰이 아니라 집행의 전제조건이었다**: 2a의 실측 — 기계 감지는
   결정이 키·값으로 **등록된 경우에만** 작동한다(등록 없는 결정은 어떤 감지기도
   못 지킨다). "서명 1회 + 나머지 전부 자동" 설계가 UX 타협이 아니라 기술
   필연임이 확인됐다.
3. **보상이 오늘 도착해야 한다**(1b의 생존 조건) × **후보는 하루 2.3건**(2b) ×
   **비용은 월 2일**(2c) — 셈이 선다: 하루 5초×2.3회의 서명으로 월 2일을 사는
   교환. 단 전부 n=1 실측이라 두 번째 사용자에서 재측정이 필요하다.
4. **부수 실발견 1건**: METHOD V1.0 §11.2 의 제3 정본 모순 — 개정 묶음(감사
   개정-5)에 등재. 백테스트 도구가 조사 중에 실전 가치를 한 번 증명한 셈.

## 조사가 유보한 것 (정직하게)

- 전부 n=1 (창업자 1인, 코딩 세션 편향, 대청소 이틀 포함 창).
- "서명하겠는가"는 전부 추정 — 창업자 본인 검토 0건. 목업 선택과 첫 실사용이
  다음 증거다.
- 모순 감지의 "안 되는 영역"(신조어 동일성·주장 검증)은 마케팅에서 약속하면
  안 된다 — 2a가 그은 선 그대로.
- 저장소 밖(외부 사용자) 수요 검증은 여전히 0 — 1b의 가장 불리한 발견(수요
  부재가 최대 사인)이 우리에게도 적용될 수 있다.
