## 오탐 실측 (최근 커밋 20개 소급 적용)

- **D1 신어휘 감지 (트리거+LLM)**: 17커밋 문서 diff 에 새 굵은 용어 ~180개, 표본 내 진짜 중복 어휘 0건 — 울리는 족족 오탐. 같은 저장소의 LLM 판정 실증 정밀도: 도달성 감사 "죽었다" 판정 9건 전부 위양성. **오탐:정탐 ≥ 5:1 — 피로사 영역.**
- **D2 비구조 정본 전체 LLM 스캔**: 승계·은퇴 커밋이 만드는 의도된 모순 다수 + recall 불완전 실증 (비판 패스가 PRODUCT.md:7 은 잡고 METHOD:1286 은 놓침). **부적격.**
- **D3 구조화 장부 (스코프 키+검색어+금지값, 결정론)**: naive grep 정밀도 18% → **금지값 페어링 시 정밀도 67%·recall 100%.** 오탐 ~1-2건/20커밋. **실용 영역.**

## 종합 판정

**되는 영역**: 결정이 키·값·검색어로 등록된 경우의 (i) 등록 순간 키 충돌 (ii) 이후 커밋의 금지값 grep. 이 저장소의 가드 테스트 3종(persistence-contract·schema-drift·no-left-accent-bar)이 같은 원리의 성공 선례 — 전부 **사람이 결정을 기계 술어로 컴파일한 뒤에만** 작동한다.
**안 되는 영역**: (i) 신조어의 개념 동일성 — LLM 필수, 현 정밀도로는 피로사 위험 (ii) 주장 vs 실코드 동작 — 검증 노동, 장부로 환원 불가 (iii) 비구조 전체 스캔.
