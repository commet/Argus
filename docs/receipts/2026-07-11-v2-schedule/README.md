## 이 디렉토리가 리포에 커밋된 이유 (원장은 원래 개인 자산인데?)

`argus_init`의 기본값은 원장을 `.gitignore`로 숨기는 것이다(결정 기록은 개인
데이터). 이 봉인만은 예외다 — 창업자가 명시 지시한 **공개 약속**이고, 팀과
미래 세션이 볼 수 있어야 도그푸딩이 성립한다. 그래서 생성된 `.argus/.gitignore`
와 기기 식별용 `.install`만 제거하고 나머지(원장·영수증·bearing seed·.ics)를
그대로 커밋했다. 다른 원장에는 이 예외를 복제하지 말 것.
