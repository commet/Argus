## 2. 이번 세션이 고친 것 (브랜치 `claude/festive-fermi-81log6` = #401 + 아래)

실제 한 바퀴(빈 저장소에서 서명 → 브리프 → 감시 → 다시 볼 날 → 닫기)와
"플러그인만 깐 기기" 재현으로 찾은 것들이다.

1. **플러그인만 깐 기기에서 결정 장부 훅 셋이 영영 침묵했다.** 훅은 PATH 의
   `argus-decision-mcp` 만 찾는데 플러그인은 엔진을 npx 로 데려오고 전역 설치를
   안 한다. → `hooks/engine.js` 한 곳에서 찾고, MCP 서버가 이미 받아 둔 **npx
   캐시 사본**을 쓴다(2.1.0 미만 사본은 거절 — 인자를 무시한 stdio 서버가 떠서
   예산을 태우므로). 재현: 전역 설치 없이 캐시에만 둔 엔진으로 세션 시작 훅이
   서명된 규칙을 편다.
2. **화면이 가르치는 명령 여섯이 그대로 치면 죽었다** — 맨 엔진 이름 + 필수
   `--argus-dir` 누락. → `ENGINE_COMMAND`(`npx -y argus-decision-mcp`) 하나로,
   `--argus-dir` 가 없으면 **이미 있는** 프로젝트 장부를 찾아 쓴다. 가드 둘.
3. **`--review +14d` 가 글자 그대로 저장돼 서명 다음 날 "오늘 다시 볼 날"로
   떴다** (`'+' < '2'`). → 날짜 깃발은 지평을 날짜로 바꾸고, 실재하지 않는
   날짜·글자는 거절.
4. **대화 안 입구가 없었다** — 결정 장부는 터미널 명령뿐이었다. 웹도 터미널도
   안 여는 사람에게 문이 0개. → `/argus:history rules`(목록·시운전·서명·다시 볼
   날). 쓰기는 서명 하나, 명시적 "예" 뒤에만.
5. 버전: 엔진 2.1.0 · 플러그인 3.1.0, CHANGELOG.
6. `.claude/settings.json` — Supabase MCP 도구 전체 허용 (창업자 지시: 승인
   대기로 작업이 멈추지 않게).
