1. **(c)/(d)가 14건 중 12건. (a)는 사실상 0건** — 단, §6의 표본 편향 주의.
2. **고통 빈도가 매일~매주**인 경우만 지속 (먹기, 회의, 타이핑, 수식, 기상). 프로젝트당 1회(ShipFast)는 쇠퇴.
3. **Time-to-value 5분 미만, 싱글플레이어, 셀프서브 결제.** 멀티플레이어는 트랙션 *이후*.
4. **최고 마진은 소프트웨어가 아니라 사람 서비스를 대체** ($300 사진사 vs $29 — 가격은 서비스에, 원가는 API 호출에 앵커).
5. **이긴 래퍼 공식: 게으른 입력(사진·음성·화면) → 모델 → 완성된 산출물.** 캡처가 아니라 *편집 단계*를 제거.
6. **14건 중 ~10건의 진짜 무기는 출시 전 보유한 유통** (팔로워, 도메인, 서브레딧, 인플루언서 머신).
7. 구매자는 "자기계발/직업 이미지에 자비 지출하는 개인" 편중. 톱다운 IT 구매 0건.
8. 속도는 니치와 결합할 때만 해자 (Chatbase→고객지원, Jenni→학술. 니치 없는 속도 ShipFast는 쇠퇴).
9. **같은 니즈가 야망 수준별 복수 승자를 부양** (Wispr $700M ↔ Superwhisper 솔로 — 받아쓰기 하나에서).

**압축된 검증 질문:** "사람들이 이미 매주, 투덜대며, 어떤 도구/서비스로 하는 일 — 모델 호출 한 번 또는 설계 결정 하나가 그 투덜거림을 지우는가? 그 사람들이 닿을 수 있는 한 채널에 모여 있는가?"

## 2. 표출된 미충족 수요 (반복 요청 증거 순)

1. **Meetup 대체재** — 다년간 반복 (Ask HN 2023/2024/2025에 걸쳐 독립 요청 + 대체재 제작 시도 반복). 막는 것: 네트워크 효과 콜드스타트. [HN](https://news.ycombinator.com/item?id=45045116)
2. **AI 슬롭 필터 / 알고리즘 없는 피드** — Ask HN 2025-10에서 유일하게 "복수 반복" 명시된 요청. 조잡한 시도들(SlopBlock, Slop Evader, Kagi SlopStop)이 수요 증명. 막는 것: 탐지 기술 불안정 + ToS 법적 리스크. [HN](https://news.ycombinator.com/item?id=45500937)
3. **기업 고스팅 트래커** ("지원 과정의 Glassdoor") — 구직자 53–61%가 고스팅 경험. 막는 것: 명예훼손 리스크, 데이터 검증. [Pin Ghosting Index](https://www.pin.com/blog/employer-ghosting-index/)
4. **음악판 Letterboxd** — 수년간 반복, 시도 다수(Musicboard 등) 승자 없음. 막는 것: TMDB급 공용 DB 부재, 커뮤니티 콜드스타트.
5. **교민 이중과세 신고 소프트웨어** — HN에서 "연 $1–2k 지불" 발화. 어려운 20%(PFIC/조세조약)가 정확히 지불 지점. 막는 것: 좁은 TAM × 국가쌍 복잡도, 책임 리스크. [HN](https://news.ycombinator.com/item?id=42599446)
6. **무료체험/구독 자동 해지** — 2019년부터 반복. DoNotPay는 FTC 제재, privacy.com은 미국 한정. 막는 것: 가맹점·카드망의 적대적 대응.
7. **무마찰 집안 물건 추적** — r/SomebodyMakeThis 단골. HomeBox/Sortly 전부 입력 마찰로 사망.
8. **로컬 디버깅 가능한 CI** — HN 개발자 위시리스트 다년 반복. 막는 것: CI 벤더의 해자가 곧 호스팅 실행.
9. **[KR] 주기 생활관리 리마인더** — 블라인드/클리앙 "이런 앱 있으면" 스레드 최다 반복 (칫솔·침구·필터 교체 주기 내장). 막는 것: "너무 단순해 보임". [Blind](https://www.teamblind.com/kr/post/이런-앱app-있으면-좋겠다-생각해본적-있는-사람-JuxXyWRj)
10. **[KR] 전 쇼핑몰 가격 추적 알림** — 폴센트는 쿠팡만, 다나와는 워치리스트 알림 부실. 막는 것: 스크래핑 차단, 제휴수수료 이해충돌.
11. **안전 중심 자전거 내비** — 부분 해결(Pointz, 미국만). 갭은 글로벌 커버리지.
12. **블로그/롱폼 취향 추천** — 반복 요청, 수익모델 부재로 미건설.

**교차 패턴:** ① 탈(脫)엔시티피케이션 수요가 2024–26 최대 (슬롭 필터, 플랫폼 탈출) — 단 ToS/법적 적대성이 양질의 구현을 막음. ② "존재하지만 마지막 20%가 곧 제품" (입력 마찰, 어려운 엣지케이스). ③ 한국 스레드는 화려하지 않은 개인 생활운영 도구로 수렴.

## 5. 종합 — 분류법 매핑

- **(a) 아무도 못 떠올린 것:** 기성 시장에선 실증 승자 부재. 유일하게 진짜 (a)가 존재하는 곳은 §4 — 고통 자체가 3년 전에 없었으므로. 단, 흡수 위험 필터 필수.
- **(b) 다들 떠올렸으나 안 만든 것:** 승부는 발명이 아니라 포장 속도(Chatbase) 또는 "시시해 보임"의 극복(Formula Bot). 교민 세금처럼 어려운 20%가 지불 지점인 경우 포함.
- **(c) 해결된-척-망가진 것:** 가장 비옥. 단 **구조적 사인을 먼저 진단** — 인센티브 역정렬(기존 업체가 못 따라옴 = 해자), 입력 마찰(LLM이 다시 염), 교차 객체(자연어가 새 상호운용 레이어).
- **(d) 마찰 10배 절감:** 래퍼 공식 = 게으른 입력 → 모델 → 완성된 산출물 (편집 단계 제거).

**Argus 관련 메모 (참고만):** 워크슬롭/AI 초안 검수(#10)는 Argus의 하중 탐침·증거 인용 규율이 그대로 이식되는 인접 영역 — 받은 문서에 겨누면 "결론을 받치는데 문서 안에 근거 없는 문장" 발화기가 됨. 단일 제품이라기보다 **진입 표면(wedge)** 후보. 약속 원장(§3 유형 3)은 Return 루프의 일반화 — 단 통합 지옥이라 솔로에겐 무거움.

## 6. 이 리서치의 한계 — 읽는 사람이 알아야 할 편향

1. **생존 편향 + 시간창 편향:** §1은 "2024–26 빠른 트랙션"만 표집 — 카테고리 창조형 제품(수년 무명기 후 개화: Notion, Letterboxd, Duolingo류)은 이 창에 **구조적으로 안 잡힌다.** "(a)형 승자 0건"은 법칙이 아니라 부분적으로 표본의 인공물.
2. **표출 수요 편향:** §2는 사람들이 *언어화할 수 있는* 결핍만 잡는다. 진짜 (a)형 기회는 정의상 위시리스트 스레드에 없다.
3. **검증 질문("매주 투덜거림")의 사각:** 이 필터는 유틸리티 게임에 최적화된 것 — 새 행동을 만들어야 하는 제품, 루프로 복리되는 제품은 이 필터를 통과 못 하면서도 성공할 수 있다 (알라미도 첫날엔 "알람은 공짜인데 누가 사?"였다).
4. 트래픽·MRR 수치는 자가 보고가 다수 — 방향은 신뢰 가능, 절대값은 ±.
