## Direction

Argus should feel like a loyal companion that sees what others miss. The mascot should carry the product's watchdog identity without becoming aggressive, militarized, or cute in a way that weakens trust.

Core traits:

- Loyal, attentive, warm
- Calmly vigilant rather than threatening
- Intelligent enough to signal judgment
- Simple silhouette that can survive small UI placements
- Compatible with the Voyage brand system: Scout, Watch, Navigator, and decision journey language

## Visual Anchors

- Upright ears and alert posture for vigilance
- Warm eyes and relaxed mouth for affection
- Shield-shaped tag for protection and trust
- Charcoal, warm white, muted copper, blue-gray, and a small signal green accent

## Expansion Set

The next usable variants should be:

1. App/avatar head mark
2. Empty-state illustration
3. Loading or "watching" state
4. Onboarding welcome pose
5. Small badge or sticker set for Scout, Watch, Cartographer, and Navigator moments

## v2 Balance

The second direction keeps the dog lovable while pulling it into Argus's existing parchment, ink, muted-gold, sea-chart language. This is the stronger product direction:

- Use the full-color dog sparingly, as a companion moment rather than the brand's first voice.
- Keep the face, shield tag, and calm watching pose as the core assets.
- Prefer quiet appearances in onboarding, loading, empty states, return/check-in moments, and small companion surfaces.
- Avoid placing the full mascot in the landing hero or primary nav where it would compete with the logbook/sea-chart identity.
- Derive smaller cutouts from the v2 sheet before using it in product screens.

## First Product Placements

Initial implementation uses the mascot in four low-authority companion moments:

- Workspace first input: a small sitting Argus reassures first-time users that one sentence is enough.
- Project empty state: sitting/head Argus replaces a generic file icon where the product is waiting for the first voyage.
- Check-in due strips: a tiny head mark signals that Argus remembered the return promise.
- Long loading only: a watching Argus appears after the wait becomes noticeable, never at the start of ordinary loading.

## Guardrails

Avoid:

- Snarling, bared teeth, chains, spikes, police or military styling
- Overly realistic breed specificity that makes the mascot harder to own
- Heavy mythology props that users must learn before understanding the UI
- Tiny details that collapse at favicon or button scale
