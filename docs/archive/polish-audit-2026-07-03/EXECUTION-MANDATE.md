## argus-mcp는 1급 시민 (창업자: "argus-mcp가 진짜 킥이야")

- MCP 감사는 총 10각도로 별도 수행됨: `11-mcp.md`(배신·첫3분·목소리·최악의날·기다림·드리프트 6각도) + `12-mcp-deep.md`(완주경험·재방문·시그니처·축적 4각도).
- **5회 리뷰 시작 전에 두 MCP 보고서를 00-MASTER.md에 통합**한다 (종합 에이전트는 9개 웹앱 보고서만 읽었으므로 통합 없이는 MCP가 실행 단계에서 누락된다).
- 실행 단계에서 MCP 항목은 웹앱 항목과 **동급 이상의 우선순위**로 구현한다. 검증도 양쪽: 웹앱 tsc + argus-mcp 자체 tsc/테스트.
- 웹앱-MCP 드리프트 발견은 코어 로직 공유(verbatim 이식 + drift 가드) 방향으로 고친다 — 프롬프트 단일소스 헌법 조항의 MCP 확장.

## 5회 리뷰 각도 (순서대로, 각각 독립 에이전트)

1. **사용자 여정** (필수) — 첫 방문 → 첫 입력 → 봉인 → 부재 기간 → 귀환 → 정산 → 재봉인의 전 구간을 한 사람의 이야기로 관통시켰을 때 플랜에 구멍이 없는가
2. **스파인/헌법 정합** — CLAUDE.md의 zero-judgment 게이트(4개 조항), 프롬프트 단일소스, 스키마 동기화, 퍼시스턴스 선언 등 헌법 위반 항목 색출
3. **기술 리스크·회귀** — 기존 데이터 호환(localStorage 구버전), PGRST204 위험, 병렬 세션 충돌(공유 등록부 4개는 append만), 삭제 시 Clean Removal
4. **노력 대비 효과·순서** — 실행 순서 재배열, 반나절 안에 못 끝낼 항목 분할, 의존관계 오류 수정
5. **적대적 회의** — 빠진 것, 과잉 설계, 기각해야 할 것, "이걸 진짜 사용자가 원하나"

각 리뷰 후 00-MASTER.md를 직접 개정하고, 개정 내역을 REVIEW-LOG.md에 남긴다.

## 대리 판단의 근거 (창업자의 과거 판단 패턴)

- 스파인 > 기능: 평결·점수·등급 노출은 무조건 기각 (여러 차례 확정)
- 정직한 표기 > 마찰 게이트: ai_surfaced 태그 + 탈출구 유지, 강제 타이핑 금지
- 절제 기본값: 개입할지 말지를 대신 판단하지 않는다 — over-fire도 위반
- 세계관 어휘(봉인·정산·항해)는 지키되, 첫 만남에만 일상어 다리를 놓는다
- 삭제보다 접기: 큰 삭제는 기존 사용자 데이터 호환 먼저 (two-door BIND 때도 창업자 OK 받고 진행했음 — 이번엔 대리판단으로 진행하되 기록)
- 랜딩의 청사진 물성을 앱 안으로 (기존 확정 방향); --bp-* 토큰은 버튼 배경 금물
- 구현했으면 실제로 검증 (tsc 0, vitest --exclude "**/.claude/**", 가능하면 preview)
- 커밋은 영어, 사용자 소통은 한국어
